- **Key Technical Features:**

#### 2. 🍲 ShareBite — Intelligent Food Rescuing & Redistribution Platform
> *A mission-driven full-stack logistics solution connecting food establishments, restaurants, and event organizers with local NGOs and shelters to eradicate food waste.*

- **Problem Solved:** Massive amounts of edible surplus food are discarded daily while communities suffer from food insecurity due to the lack of real-time supply-chain coordination.
- **Key Technical Features:**
  - Real-time geospatial matching engine routing surplus food listings to nearby verified hunger relief organizations.
  - Automated dispatch notification system utilizing geo-fencing and status-tracking pipelines.
  - Role-based dashboard for donors (restaurants, caterers) and recipients (NGOs, community volunteers) with verification safeguards.
  - Analytics overview reporting total kilograms of food salvaged and carbon footprint averted.
- **Tech Stack:** `TypeScript` `React / Next.js` `Node.js` `PostgreSQL / Prisma` `Mapbox / Leaflet` `Tailwind CSS`
- **Links:** [Repository](https://github.com/YOUR_GITHUB_USERNAME/sharebite) • [Live Demo](https://sharebite-demo.com)

#### 3. 🧠 NoteWise AI — Contextual Chat with Your Notes (RAG-Powered)
> *An intelligent document interrogation platform turning dense notes, PDFs, and textbooks into queryable, interactive knowledge graphs using state-of-the-art LLMs.*

- **Problem Solved:** Eliminates passive reading and inefficient manual search across extensive lecture notes and study material through deterministic, cited contextual answers.
- **Key Technical Features:**
  - Multi-document RAG pipeline implementing dynamic recursive character chunking and semantic vector embeddings.
  - Vector similarity search with hybrid keyword fallback to minimize hallucinations and deliver citation-backed answers.
  - Multi-format ingestion support (PDFs, Markdown, DOCX, TXT) with asynchronous background processing workers.
  - Session-based conversation memory preserving context across multi-turn reasoning workflows.
- **Tech Stack:** `Python` `FastAPI` `LangChain / LlamaIndex` `ChromaDB / Pinecone` `OpenAI / Local LLMs` `Next.js` `Tailwind CSS`
- **Links:** [Repository](https://github.com/YOUR_GITHUB_USERNAME/notewise-ai) • [Live Application](https://notewise-ai-demo.com)
