### 2. NoteWise AI — Intelligent Document Assistant

**Turning documents into interactive knowledge.**

NoteWise AI is an AI-powered document assistant built around Retrieval-Augmented Generation (RAG). It enables users to interact with their documents using natural language and retrieve relevant information through contextual AI responses.

**Key Features**

| Feature | Description |
|---|---|
| Multi-format Support | PDF, DOCX, PPTX, TXT, XLSX |
| Document Q&A | Ask questions in natural language |
| Contextual Retrieval | Retrieve relevant document information |
| AI-powered Responses | Generate context-aware answers |
| Knowledge Extraction | Simplify complex document analysis |

**Technology Focus:** Python, AI/ML, LLMs, RAG, Document Processing, Vector Search.

**Goal:** Making document understanding, information retrieval, and learning more intelligent and accessible.

### 3. ShareBite — Food Sharing & Redistribution Platform

<p>
  <a href="https://sharebite-final.vercel.app/">
    <img src="https://img.shields.io/badge/Live%20Application-ShareBite-16A34A?style=flat-square" alt="ShareBite Live"/>

**Reducing food waste. Connecting communities. Creating impact.**

ShareBite is a community-driven food redistribution platform that connects food donors, NGOs, volunteers, recipients, and delivery partners to make surplus food accessible to people in need.

**Key Features**

| Feature | Description |
|---|---|

| Location-based Discovery | Nearby NGO and food discovery |
| Interactive Maps | Location-based coordination |
| Volunteer Management | Volunteer and delivery coordination |
| Real-time Tracking | Food distribution monitoring |

**Technology Stack:** React Native, JavaScript, Supabase, PostgreSQL, Maps Integration.

**Project:** [sharebite-final.vercel.app](https://sharebite-final.vercel.app/)

**Impact:** Supporting food accessibility, community participation, and sustainable food redistribution.
